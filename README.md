
# Сетевая система для бронирования и управления расписанием помещений

Курсовой проект.

## Технологии

- Python 3.14
- PySide6
- PostgreSQL 18
- Psycopg 3
- TCP sockets
- JSON
- pytest
- Git

## Архитектура

Приложение состоит из двух независимых частей:

- Клиентское приложение — графический интерфейс пользователя.
- Серверное приложение — обработка запросов, бизнес-логика и работа с базой данных.

Обмен данными между клиентом и сервером осуществляется по TCP с использованием JSON.

## Структура проекта

- client — клиентское приложение.
- server — серверная часть.
- shared — общие компоненты и сетевой протокол.
- tests — автоматические тесты.

## Запуск

Инструкция по запуску будет дополнена после реализации основных компонентов.
